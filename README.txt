・7狙い → チェリー1コマ / スイカ3コマ
・8狙い → チェリー2コマ / スイカ4コマ
・9狙い → チェリー3コマ / スイカ5コマ

つまり左リールを7・8・9付近で止めれば、
チェリーとスイカの両方を最大5コマアシスト範囲でフォロー可能。
